# PROJECT SOVEREIGN

**Public Alpha v0.6.0 — Playability & UX Update**

政策を選ぶ意味、次にやるべきこと、ターン結果の理由が分かることを重視した、PCブラウザ向け国家運営シミュレーションです。

## v0.6.0の主な改善

- 操作画面を「指令室」「国家方針」「危機・イベント」「国家プロジェクト」の4画面へ整理
- 情報確認を「国家分析」「国家年表」の2画面へ分離
- クリックごとの全画面再描画を廃止し、必要な領域だけを更新
- スクロール位置・入力フォーカスを維持
- 月報を、選択・実結果・政策なしの場合との比較・次の行動が分かるターン結果へ変更
- 条件・定期・ランダム・連鎖イベントが共存するイベント受信箱
- 操作フィードバック、数値変化、ターン進行の短いアニメーション
- `prefers-reduced-motion`によるモーション軽減対応
- 月次赤字の自動借入と財政原因の表示
- 商品価格の暴騰抑制、供給回復、基準価格へ戻る市場調整
- 倒産企業の再建・買収・清算・新規参入
- v0.5セーブデータと長期プレイデータの自動移行

## ゲームの基本導線

1. 指令室で「今やるべきこと」と対応待ちイベントを確認
2. 国家方針または国家プロジェクトで判断を入力
3. 未確定命令を確認してターンを進める
4. ターン結果で、判断による効果・自然変動・イベント影響を確認
5. 国家年表で過去の判断と指標推移を振り返る

## Cloudflare Workers設定

| 設定 | 値 |
|---|---|
| Build command | `bash cloudflare-build.sh` |
| Build output directory | `dist` |
| Root directory | 空欄 |
| Production branch | `main` |
| Node.js | `22.16.0` |
| Deploy command | `npx wrangler deploy` |
| Worker name | `project-sovereig` |

`wrangler.jsonc`では、`dist`を静的アセットとして公開します。ビルド時にはv0.2からv0.6までの検証済み差分を順番に復元し、テスト・型検査・静的ビルド・公開物検査を通過した場合だけデプロイへ進みます。
