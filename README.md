# PROJECT SOVEREIGN

**Public Alpha v0.7.3 — Command Room, National Map & War Room Update**

経済、企業、国民、政治、外交、軍事が連動するブラウザ向け国家運営ゲームです。v0.7.3では、指令室を国家運営の中心画面へ再構成し、国内状況マップと戦争の開戦前・交戦中・講和・戦後を一つのゲームループへ接続しました。

## ゲーム開始

新規ゲームでは次の3項目を選びます。

1. 国家
2. 国家目標
3. 秘書官

国家目標は「経済大国」「福祉国家」「外交連邦」「軍事覇権」「国家存続50年」の5種類です。

| 秘書官 | 得意分野 | 特徴 |
|---|---|---|
| 九条 澪 | 財政・内政・危機管理 | 危機対応費-5%、外交関係改善-5% |
| 天城 ひなた | 外交・貿易・国民支持 | 外交改善+8%、国際評価回復+5%、戦費+5% |
| 黒崎 蓮 | 軍事・安全保障 | 即応度回復+8%、防衛疲弊-10%、福祉支持回復-5% |

v0.7.3は新規開始専用です。旧バージョンのセーブデータは移行しません。v0.7.0以前のセーブも対象外です。v0.7.3で作成したセーブは保存、再開、JSON入出力に対応しています。

## v0.7.1：指令室2.0

- 国庫、政治資本、未確定命令、主要国家指標をコンパクトに表示
- 最重要案件を最大3件に絞り、原因、放置時の影響、推奨対策を提示
- 秘書官の提案を「採用」「詳細確認」「見送り」から選択
- 採用時は提案への回答と推奨命令を未確定命令へ追加
- 国庫、成長率、支持率、債務、物価、失業率の先月比と原因を表示
- 案件や地域から対応する政策・事業・分析画面へ直接移動

## v0.7.2：国内状況マップ

指令室中央に、自国3地域を表すオリジナルSVGマップを常設しました。新しい常設タブは追加していません。

表示レイヤー：

- 総合
- 経済
- 雇用
- 国民生活
- 地域基盤
- 資源
- 危機・戦争被害

地域を選ぶと、人口、主要産業、安定度、雇用率、幸福度、怒り、企業状態、公共事業、危機、戦線、主な問題と推奨対策を確認できます。拡大表示でも地図操作を継続できます。

## v0.7.3：戦況指令室

国防画面は国家状況に応じて自動的に切り替わります。

1. **開戦前**：対象国、開戦目的、月額戦費、期間、人的損失、国際反応、敗北リスクを比較
2. **交戦中**：戦況、累計戦費、損耗、疲弊、前線ごとの補給・地域被害・戦闘激度を表示
3. **講和判断**：獲得物と代償を確認し、講和姿勢と占領統治を選択
4. **戦後秩序**：資源権益、貿易路、領土税収、占領抵抗、月次純効果を継続表示

交戦中は次の国家レベルの作戦方針を選べます。

| 方針 | 特徴 |
|---|---|
| 戦力温存 | 戦費と損耗を抑え、補給を守る。進軍は遅い |
| 均衡作戦 | 戦費、損耗、進軍を標準水準で維持 |
| 突破作戦 | 進軍と戦闘力を高める。戦費、損耗、補給負担、地域被害が増える |

同じシード、国家状態、命令では同じ戦況になります。

## ゲームオーバーとエンディング

敗北条件は財政破綻、政権崩壊、軍事クーデター、戦争敗北、国家崩壊です。危険度、原因、回避条件、残り月数を指令室に表示します。

国家目標の条件を12か月維持するとエンディングを解放します。通常エンディングに加え、秘書官との絶対的信頼、非戦大国化、複数回の国家救済などによる隠しエンディングがあります。

## 日本円表示

内部値`1B`を`10億円`として表示します。国庫、予算、税収、債務、企業売上、貿易、戦費、賠償金は万円・億円・兆円へ自動変換されます。

## PC・スマートフォン

- PCでは、重要案件・秘書官・国内マップ・地域詳細を2カラムで表示
- スマートフォンでは、上部操作、横スクロール可能な命令バー、本文、下部ナビゲーションへ再配置
- 地図と地域詳細は1カラムへ切り替え
- 横方向のページはみ出しを防止
- `prefers-reduced-motion`に対応
- ブラウザ標準の`alert`・`confirm`は使用せず、ゲーム専用ダイアログを使用

## 基本操作

1. 指令室で最重要案件、秘書官提案、先月比、国内マップを確認
2. 地域または案件から対応する政策・事業・危機画面を開く
3. 未確定命令を確認してターンを進める
4. 戦争中は作戦方針と各前線の補給・損耗を確認
5. ターン結果と国家年表で、判断の効果と原因を振り返る
