# PROJECT SOVEREIGN

**Public Alpha v0.7.0 — Political Drama Update**

経済、企業、国民、政治、外交、軍事が連動するPCブラウザ向け国家運営ゲームです。v0.7では、3人の秘書官、明確なゲームオーバー、目的を選ぶ戦争、勝利報酬、複数エンディングを追加しました。

## ゲーム開始

新規ゲームでは次の3項目を選びます。

1. 国家
2. 国家目標
3. 秘書官

国家目標は「経済大国」「福祉国家」「外交連邦」「軍事覇権」「国家存続50年」の5種類です。

秘書官は次の3人から選択します。

| 秘書官 | 得意分野 | 特徴 |
|---|---|---|
| 九条 澪 | 財政・内政・危機管理 | 危機対応費-5%、外交関係改善-5% |
| 天城 ひなた | 外交・貿易・国民支持 | 外交改善+8%、国際評価回復+5%、戦費+5% |
| 黒崎 蓮 | 軍事・安全保障 | 即応度回復+8%、防衛疲弊-10%、福祉支持回復-5% |

旧バージョンのセーブデータは移行しません。v0.7の新規ゲームとして開始してください。v0.7で作成したセーブは保存、再開、JSON入出力に対応しています。

## v0.7の主な機能

### 秘書官と指令室

- 上半身立ち絵、小アイコン、5表情
- 国家状況に応じた月次報告
- 最優先の危機、好機、推奨行動を最大3項目で提示
- 信頼度と負荷の変化
- 国家目標の進捗と次の未達条件を常時表示

### ゲームオーバー

- 財政破綻
- 政権崩壊
- 軍事クーデター
- 戦争敗北
- 国家崩壊

危険度、原因、回避条件、残り月数を指令室に表示します。戦争敗北以外は最後の救済判断が発生します。

### 戦争

攻撃戦争では、同盟国防衛、資源確保、貿易路確保、領土拡張、政権転覆から目的を選びます。開戦前に月額戦費、想定期間、人的損失、国際反応、利益を確認できます。

勝利後は講和姿勢と占領統治を選びます。資源権益、貿易路、領土税収は毎月の国庫・貿易収支へ反映され、占領抵抗には毎月の統治費と安定度低下が発生します。戦争画面の「戦後権益」で月次純効果を常時確認できます。

### エンディング

国家目標の条件を12か月維持するとエンディングを解放します。通常エンディングに加えて、秘書官との絶対的信頼、非戦大国化、複数回の国家救済などによる隠しエンディングがあります。

### 日本円表示

内部値`1B`を`10億円`として表示します。国庫、予算、税収、債務、企業売上、貿易、戦費、賠償金は、万円・億円・兆円へ自動変換されます。

## 基本操作

1. 指令室で秘書官の報告、国家目標、敗北リスクを確認
2. 国家方針、危機・イベント、国家プロジェクトで判断を入力
3. 未確定命令を確認してターンを進める
4. ターン結果で効果、自然変動、イベント影響を確認
5. 国家年表で過去の判断を振り返る
