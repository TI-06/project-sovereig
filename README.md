# PROJECT SOVEREIGN

**Public Alpha v0.6.2 — Crisis Guidance Update**

政策を選ぶ意味、次にやるべきこと、ターン結果の理由が分かることを重視した、PCブラウザ向け国家運営シミュレーションです。

## v0.6.2の主な改善

- 指令室の危機カードを「回避策を見る」導線へ変更
- 危機ごとに原因、今すぐ行うこと、次の3か月を表示
- 避けるべき行動と危機脱出条件を明示
- 国庫枯渇、貿易赤字、企業倒産増加を含む8種類の危機ガイド
- 危機と相性のよい国家方針を最大2件提示
- 即効型、均衡型、構造改革型の3対策を表示
- 対策を税率、金利、予算の未確定命令へ反映
- 国家方針と詳細対策を同時実行しても詳細値が上書きされないよう修正

## v0.6のゲーム導線

1. 指令室で「今やるべきこと」と対応待ちイベントを確認
2. 危機カードの「回避策を見る」で具体的な回復手順を確認
3. 国家方針または3つの対策案を選択
4. 未確定命令を確認してターンを進める
5. ターン結果で判断、自然変動、イベント影響を確認
6. 国家年表で過去の判断と指標推移を振り返る

## 主なシステム

- 操作画面：指令室、国家方針、危機・イベント、国家プロジェクト
- 情報画面：国家分析、国家年表
- 条件、定期、ランダム、連鎖イベントが共存するイベント受信箱
- 月次赤字の自動借入と財政原因の表示
- 商品価格の暴騰抑制、供給回復、基準価格へ戻る市場調整
- 倒産企業の再建、買収、清算、新規参入
- v0.5セーブデータと長期プレイデータの自動移行
