# v0.7 CI Expectations

The pull-request workflow must:

1. Reconstruct v0.2 through v0.6.2.
2. Concatenate exactly 13 v0.7 Base64 chunks.
3. Verify the Base64, XZ and decompressed patch SHA-256 values.
4. Apply the patch and require package version `0.7.0`.
5. Run `npm run verify`.
6. Validate v0.7 deployment files and Japanese UI markers.
7. Upload the build log, reconstructed source and static distribution.
